## 주요 기능

| 기능 | 설명 |
| --- | --- |
| **서재 관리** | 도서 정보·표지·주제·구매처를 관리하고 목록과 표지 보기로 탐색합니다. |
| **검색과 필터** | ISBN·도서명·저자·출판사로 검색하고 주제·구매처로 결과를 좁힙니다. |
| **서재 통계** | 전체 권수와 주제·구매처·구매 연도별 분포를 확인합니다. |
| **잠금과 백업** | 로컬 암호화 저장, PIN 화면 잠금, 비밀번호로 보호하는 백업·복원을 제공합니다. |
