주제별 칩 색상

기존 14색과 주제명 기반 배정을 유지합니다. 위 주제명은 기존 테스트의 예시이며 실제 서재 데이터가 아닙니다. 두 도서의 주제가 모두 프로그래밍이므로 목록의 칩은 같은 색이 맞습니다.

전체 토큰은 DESIGN.md에 정의합니다. 입력 경계(control)와 장식 구분선(rule)은 서로 다른 역할입니다.
